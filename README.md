# 拾光小镇 · 像素生活工作台 🌱

一个轻松治愈的像素风单页应用：把待办、记账、习惯打卡、AI 新闻、学习计划、英语练习、体重记录和每日复盘，装进一座会呼吸的小镇。完成任何一件小事都会获得 **XP 和金币**，并**自动给花园里的植物浇水**——让每天的进步都被看见。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，浏览器打开提示的地址（默认 http://localhost:5173）
npm run build      # 产物是单个自包含的 dist/index.html（约 1.5MB），双击即可离线打开
```

> `npm run build` 用了 `vite-plugin-singlefile`：JS/CSS/字体全部内联进一个 HTML，现代浏览器下**双击 dist/index.html 就能用**，不用起服务器（`<script type="module">` 的 file:// CORS 问题已绕开，详见 [踩坑指南](./踩坑指南.md) 第 13 条）。

首次打开自带演示数据，所有数据保存在**浏览器 localStorage**（250ms 防抖自动保存）。设置里可以导出 / 导入 JSON 备份、重置小镇。

开发过程中的真实踩坑记录（中文像素字体、GSAP×StrictMode、RSS 存活名单、file:// CORS 等 15 条）见 **[踩坑指南.md](./踩坑指南.md)**。

## 游戏化规则（宽恕优先，只有奖励没有惩罚）

- 完成待办 +10 XP / 5 金币 · 习惯打卡 +8 XP / 3 金币 · 答对单词 +4 XP · 记录体重 +5 XP · 复盘 +15 XP
- 每次获得奖励，花园最需要的那盆植物自动 +1 生长点（种子 → 发芽 → 幼苗 → 花苞 → 盛开）
- 浇水壶：每天第一次免费，之后 2 金币一次
- 今日 XP 冲到 25/50/80/120 可开四个奖箱（金币奖励），升级有礼花和 8-bit 号角
- 连续投入天数：只要当天拿到过任何奖励就 +1，断一天也不会清零羞辱你

## 智能体「阿咕」

- **离线小精灵（默认）**：纯本地规则，能查询待办 / 账单 / 体重 / 学习进度，还能直接执行：
  - `帮我记一条待办：明天交报告`
  - `记账 25 午饭`
- **大模型模式**：设置 → 智能体，选择预设（DeepSeek / Kimi / 通义 / 智谱 / OpenAI）或自定义，填入 OpenAI 兼容接口的 Base URL、API Key、模型名。阿咕会把你的小镇数据摘要注入 system prompt，回答更懂你。Key 只存在你的浏览器里，请求直连服务商。

## 技术栈

- Vite + React 19 + 原生 CSS（无 UI 框架）
- GSAP 3 + @gsap/react（`useGSAP` 管理页面过渡、数字滚动、礼箱心跳、彩带、闪卡翻转、云朵漂移；尊重 `prefers-reduced-motion`）
- 中文像素字体：缝合像素字体 Fusion Pixel（npm 自托管分片 webfont，离线可用）
- 所有像素画（植物、阿咕、礼箱、心情脸…）都是手绘字符画 + Canvas 渲染，零图片资源
- 8-bit 音效由 WebAudio 现场合成（可在设置关闭）
