# 拾光小镇 · 像素生活工作台 🌱

一个轻松治愈的像素风单页应用：把待办、记账、习惯打卡、AI 新闻、学习计划、英语练习、体重记录和每日复盘，装进一座会呼吸的小镇。完成任何一件小事都会获得 **XP 和金币**，并**自动给花园里的植物浇水**——让每天的进步都被看见。

v0.7.0 新增：**🗑️ 删除全走回收站（30 天可恢复）**、**⌘K 快速输入**（智能日期捕捉/记账/全局搜索）、**🎧 专注声音**（雨声/白噪/篝火/生成式钢琴，WebAudio 现场合成）、**🎯 月度目标 + 💬 每日一问**、**🔄 多端云同步**（可选，部署到自己的 CloudBase）。

v0.8.0 新增：**🌌 夜间星空**（夜间时段背景浮现像素星空与偶发流星，canvas 2D 像素化转译、零新资源）与 **🍅 专注氛围层**（番茄钟专注时全屏叠像素扫描线+暗角，休息轮自动熄灭）——对标 ThreeUI 组件渲染氛围的像素化转译，构建体积仅 +3.2KB，见 [对标ThreeUI优化方案.md](./对标ThreeUI优化方案.md)。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，浏览器打开提示的地址（默认 http://localhost:5173）
npm run build      # 产物是单个自包含的 dist/index.html（约 0.63MB / gzip 约 0.25MB），双击即可离线打开
```

Windows 下想最快打开应用：双击根目录的 **「一键启动.bat」**——自动选一个空闲端口起 `npm run dev`（`--strictPort` 固定，不会因端口占用跳变；`.https/` 存在时自动走 HTTPS），等服务器就绪后用默认浏览器打开，dev 窗口关掉即停。等效命令 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start-app.ps1`。

> `npm run build` 用了 `vite-plugin-singlefile`：JS/CSS/字体全部内联进一个 HTML，现代浏览器下**双击 dist/index.html 就能用**，不用起服务器（`<script type="module">` 的 file:// CORS 问题已绕开，详见 [踩坑指南](./踩坑指南.md) 第 13 条）。`dist/` 里还有 `sw.js / manifest.webmanifest / icon.svg`——线上部署后即成为可安装的 PWA；本地 file:// 打开时 SW 静默跳过。

### 本地 HTTPS 用于手机真机安装 PWA

如果想在本机局域网环境让手机体验「添加到主屏」，先运行一键脚本生成证书：

```powershell
# PowerShell：执行完会生成 .https/cert.pem + key.pem + ca.pem
# 把 ca.pem 发给手机安装信任（iOS 需要额外开启证书完整信任）
pwsh scripts/https-setup.ps1  # 或 powershell -ExecutionPolicy Bypass -File scripts/https-setup.ps1
# 证书已包含 localhost + 本机全部局域网 IP，换网段后重跑脚本即可
npm run dev  # 检测到 .https/ 自动启用 HTTPS，按提示用局域网 IP 访问即可
```

首次打开是一座空白的小镇——账本、待办、习惯、体重等都没有预置数据，**所有记录都靠你自己动手**。数据保存在**浏览器 localStorage**（250ms 防抖自动保存，关页/切后台有兜底）。设置里可以导出 / 导入 JSON 备份（导入前有确认预览）、配置 WebDAV 云备份、重置小镇。存档自带版本号与迁移逻辑，旧档升级无需手动处理。

**备份方案 A（免费，推荐）：手动导出 + 坚果云同步**——设置 → 数据 → 「导出备份」下载一个 JSON（不含密钥），把它放进坚果云客户端的同步文件夹（如 `D:\Nutstore\我的坚果云`），云端即自动多一份；换设备时「导入备份」选中该文件即可接上。首次未导出时设置页会显示「备份三步走」引导卡；超过 7 天没导，首页会自动弹一次提醒。注：坚果云 WebDAV 接口已限制浏览器直连（CORS），应用内「备份到网盘」一键按钮当前不可用，走手动导出即可。

## 游戏化规则（宽恕优先，只有奖励没有惩罚）

- 完成待办 +10 XP / 5 金币 · 习惯打卡 +8 XP / 3 金币 · 答对单词 +4 XP · 记录体重 +5 XP · 复盘 +15 XP · 番茄钟专注 15~60 分钟 5~30 XP
- **难度分级**：待办/习惯可选 简单/普通/困难，奖励按 ×0.6 / ×1 / ×1.6 缩放（项目前设置里有标注）
- 每次获得奖励，花园最需要的那盆植物自动 +1 生长点（种子 → 发芽 → 幼苗 → 花苞 → 盛开）
- 浇水：每盆植物都能**单独浇水**（点植物卡片的 💧 按钮只浇那一盆，全局「浇水壶」自动浇最缺水的一盆）；每天第一次免费，之后 2 金币一次；已盛开的盆不会被浇水
- 植物盛开后来「采集种子」换 6 金币、记入图鉴；空盆可种下已解锁的任意品种
- 商店：第四/五花盆 60/120 金币 · 种子 30~45 金币（买一次永久解锁）· 装饰 50~90 金币 · 阿咕的帽子 20~60 金币 · **愿望货架自定义现实奖励（自己定价）**
- 今日 XP 冲到 25/50/80/120 可开四个**盲盒礼箱**：金币金额随机浮动 ±30%，8% 概率开出「惊喜」（解锁一颗未拥有的种子或 +25 金币）；升级有礼花和 8-bit 号角
- **每周挑战**：每周一自动抽一个周目标（如专注 180 分钟 / 15 件待办 / 习惯 20 次），达成自动发金币，下周换新的（不重复）
- 成就 16 枚 + **自定义成就**（计数指标或手动心愿）解锁送金币；写复盘、专注番茄、深夜奋斗也有专属奖杯
- 连续投入天数：只要当天拿到过任何奖励就 +1，断一天也不会清零羞辱你

## 智能体「阿咕」

- **离线小精灵（默认）**：纯本地规则，能查询待办 / 账单 / 体重 / 学习进度，还能直接执行：
  - `帮我记一条待办：明天交报告`
  - `记账 25 午饭`
- **大模型模式**：设置 → 智能体，选择预设（DeepSeek / Kimi / 通义 / 智谱 / OpenAI）或自定义，填入 OpenAI 兼容接口的 Base URL、API Key、模型名。阿咕会把你的小镇数据摘要注入 system prompt，回答更懂你；支持 **SSE 流式输出**，还能通过 `[ACT:todo_add:…]` / `[ACT:ledger_add:…]` 标记**直接帮你记待办、记账**（前端解析执行）。Key 只存在你的浏览器里，请求直连服务商。

## 天气与数据

- 真实天气三档可选：**📍 跟随定位**（浏览器定位权限，坐标直接查预报 + 免费逆地理编码显示城市名，坐标缓存 30 分钟）、**🏙️ 指定城市**、或关闭（小镇预言伪随机）。open-meteo 免费接口缓存 2 小时；拒绝定位/断网自动回退「小镇预言」
- 备份：手动导出 JSON（超过 7 天未备份首页会轻声提醒）/ **WebDAV 云备份**（坚果云等，需网盘支持浏览器跨域）/ 导入前有存档摘要确认 / **云端快照**（开启云同步后可一键备份、按快照恢复）
- 删除保护：所有记录类删除先进**回收站 30 天**，误删随时找回（设置 → 数据 → 回收站）
- 账本支持导出 CSV（Excel 直接打开）

## 多端同步（可选）

数据默认只存在本机；想在手机 / 电脑多台设备之间实时同步，可以部署一套自己的云函数到**腾讯云开发 CloudBase**（个人免费额度足够，数据完全在自己名下，协议参考自同作者的 personal-workbench）：

1. 打开 [CloudBase 控制台](https://tcb.cloud.tencent.com/) 创建一个环境（记下环境 ID）
2. 安装 CloudBase CLI 后在项目 `cloud/` 目录执行部署（首次会让你登录）：
   ```bash
   npm i -g @cloudbase/cli
   cd cloud
   tcb framework deploy --envId 你的环境ID
   ```
   会部署 `gate`（访问密码门）和 `sync`（同步/快照）两个云函数并开启 HTTP 访问，部署完成后地址形如 `https://你的环境ID.service.tcloudbase.com`
3. 小镇 设置 → 🔄 云同步：填入该地址，自设一个**至少 4 位的访问密码**（多台设备填同一个密码就是同一份数据）→ 「连接并开启同步」

之后改动会自动双向同步（本地改动 3 秒内推送；每 5 分钟和恢复联网时拉取），还可「备份到云端」做手动快照、随时从快照恢复。API Key / WebDAV 密码**永不上云**，访问密码只在本机换取同步令牌。不想用了点「退出同步」，本机数据分毫不差。

## 技术栈

- Vite + React 19 + 原生 CSS（无 UI 框架）
- GSAP 3 + @gsap/react（`useGSAP` 管理页面过渡、数字滚动、礼箱心跳、彩带、闪卡翻转、云朵漂移；入场动画一律 `fromTo + overwrite`，尊重 `prefers-reduced-motion`）
- 中文像素字体：缝合像素字体 Fusion Pixel（npm 自托管分片 webfont，离线可用）
- 所有像素画（植物 6 种、阿咕、礼箱、心情脸、装饰、帽子、奖杯…）都是手绘字符画 + Canvas 渲染，零图片资源
- 8-bit 音效由 WebAudio 现场合成（可在设置关闭）；**专注声音面板**四路音源（雨声/白噪/篝火/生成式钢琴）同样 WebAudio 全实时合成、零音频文件；单词发音用浏览器自带 speechSynthesis
- 数据层：reducer 单一真相 + localStorage 持久化 + **记录级 `updatedAt` / `_touched` 时间戳**（回收站软删除与多端同步的合并依据）+ 存档版本迁移
- 多端同步：纯函数合并引擎（记录级 LWW + 墓碑删除传播）+ 自部署 CloudBase 云函数（`cloud/`，可选）
- 可安装 PWA（manifest + Service Worker，public/ 输出，线上部署后可装桌面/主屏离线用）+ 番茄钟**系统通知**（设置里开启才申请权限）+ **暗色主题**（跟随 `prefers-color-scheme`）+ **小镇昼夜**（清晨/白天/黄昏/夜晚自动换天）+ **首次启动 3 步引导** + 移动端**底部导航**与滑动切页

## 键盘快捷键

`Ctrl/Cmd+K` 快速输入（记待办 / 记账 / 搜索 / 跳页，任何页面可用），数字键 `1-9`、`0`、`-` 快速切换页面（输入框聚焦时自动失效），`Esc` 关闭弹窗。
