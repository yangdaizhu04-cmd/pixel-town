# 拾光小镇 · 优化方案

> 记录时间：2026-09-07
> 说明：结合 Habitica / 人升(LifeUp) / Forest 三个同类标杆的调研，输出项目可优化的方向与分批落地路线。进度登记在 [优化清单.md](./优化清单.md)。

## 一、结论

项目底子好：游戏化闭环完整（XP/金币/花园/商店），「轻量、离线、治愈」是差异化优势。优化重点不在堆功能，而在三件事：

1. **意义感不够深**——奖励全是固定数值（+10 XP / +5 金币一刀切），做难事和划水没区别；
2. **数据洞察没做**——积累的数据没有反哺（无周报、无番茄统计）；
3. **形态没有进化**——纯网页，可用性天花板低（无 PWA、无系统通知、无暗色模式）。

## 三、分批评优项

### 🟥 第一批：玩家立刻能感受到的（游戏化深度）

1. **任务难度分级** ✅已落地（6f16696）：待办/习惯加「🌱 简单 / ⭐ 普通 / 🔥 困难」难度，XP/金币按难度阶梯给（简单 ×0.6、普通 ×1、困难 ×1.6），做难事有实打实的区别。
2. **自定义成就** ✅已落地（6f16696）：成就墙支持自定义「计数型成就」（如"读完 10 本书"：选指标 + 目标值，自动检测）+「手动心愿」两种，设奖励金币，解锁并入奖杯墙。
3. **愿望货架（现实奖励）** ✅已落地（6f16696）：商店新增一栏，自己「许愿」（写文字 + 定价格，如"看一场电影 50 金币"），买下后挂在货架上随时激励自己，兑现可标记。

### 🟨 第二批：让数据产生价值（洞察 + 分享）✅全部已落地（3573e90）

4. **自动周报** ✅：周末汇总一周待办/番茄/金币/植物成长，写进复盘页（复盘页「每周小结」，可回看前几周）。
5. **番茄钟统计页** ✅：学习页「专注分布」——近 14 天时长 + 时段分布（清晨/上午/下午/晚间/深夜）。
6. **成就分享卡片** ✅：年鉴「📸 分享卡」一键渲染像素分享图（canvas 保存 PNG）。
7. **奖箱盲盒化** ✅：金额 ±30% 随机，8% 概率开出未拥有的种子或 +25 金币。

### 🟩 第三批：形态进化（PWA + 移动 + 多端）✅全部已落地（2859142）

8. **PWA 化** ✅：manifest + Service Worker + 像素图标，桌面/手机「添加到主屏」，App 感运行、离线可用；设置里有安装按钮。
9. **番茄钟系统通知** ✅：专注/休息结束用 Notification API 提醒；设置里开启才申请权限（soft opt-in）。
10. **暗色主题** ✅：像素风暗色，跟随 `prefers-color-scheme`。
11. **移动端触屏适配** ✅：窄屏底部 Tab + 滑动切页。

### ⚪ 技术债（顺手清）✅ 全部已落地（2026-09-07）

12. **字体子集化压体积** ✅：843KB→82KB，dist 1648→612KB（gzip 244KB）；`scripts/subset_fonts.py` 一键复现。
13. **清理 28 条 lint 告警** ✅：归零（真修 + 配置收编刻意模式）。
14. **WebDAV 自动备份定时化** ✅：每天首次访问自动备份（云端实测待用户凭据）。
15. **pomo / store 迁移补单元测试** ✅：vitest 17 用例全过。

## 四、落地顺序

- 第一批（先做）：1 → 2 → 3，纯前端、改动小、感知最强。
- 第二批（两周内）：4 → 5 → 6，建立在第一批数据上。
- 第三批（按需）：8 → 9 → 11 打包成一次「移动化改造」。
- 远期（需后端，暂缓）：好友合种/小镇互通——会破坏「零服务器」的纯粹性。

# 第二批优化方案：竞品对比版（2026-09-09，待落地）

> 背景：对 Habitica / Loop Habit Tracker / Forest / 滴答清单 等 2026 年在售优秀产品做了公开功能对比（见下方案内「参考来源」），找出的**最大差距是「数据统计深度」**——Loop 有习惯强度评分/日历热力图/最佳连续，Forest 有日周月年报表，本项目目前只有 XP 热力图 + 周报 + 专注墙，缺"让用户看见成长"的洞察层。游戏化、AI（阿咕）、离线隐私、零成本已是第一梯队，**优化重点 = 数据感知 + 留存防丢**。

## 一、竞品差距速览

| 维度 | Habitica | Loop | Forest | 拾光小镇（本项目） |
| --- | --- | --- | --- | --- |
| 数据统计深度 | 中（成就壁） | **强**（评分·日历热力·最佳连续） | **强**（日/周/月/年） | 中（热力+周报）← 最大差距 |
| 习惯灵活度 | 中（正/反习惯+周期） | **强**（每周N次·数值型） | 弱 | 中（每日打卡+难度） |
| 游戏化激励 | 强（RPG·职业·副本） | 弱（极简） | 强（种树·90+树种） | **强**（花园·挑战·成就） |
| AI 助手 | 无 | 无 | 无 | **强**（阿咕，独有） |
| 离线/隐私 | 云端账号 | 强（纯本地·开源） | 需登录 | **强**（本地+PWA 离线） |
| 成本 | 免费+订阅 | 免费开源 | 付费/内购 | 免费自建 |

## 二、方案明细（P0 / P1 / P2）

### 🟥 P0 · 先做 —— 补「数据感知」短板（对标 Loop / Forest）

| # | 做什么 | 改动落点 | 复杂度 |
| --- | --- | --- | --- |
| P0-1 | **习惯强度评分 + 完成率趋势**：Loop 式算法（连续完成增强、错过衰减、一次失误不清零），打卡页展示评分与近 N 周完成率 | `store.jsx` 新增 `habitScore` 计算 + `Habits.jsx` 展示 | 中 |
| P0-2 | **数值型习惯**：喝水记"×杯"、读书记"×页"，不再只打勾（`days` 从 `{date:1}` 升 `{date:value}`） | `store.jsx`（需迁移兜底）+ `Habits.jsx` 输入改数值 | 中高 |
| P0-3 | **专注/账本/体重月度·年度报表**：Forest 式"日/周/月/年"粒度切换 | 复用 `weekly.js` + `charts.jsx`，各页加时间粒度切换 | 中 |
| P0-4 | **灵活排期**：每周 3 次、隔天一次（Loop 招牌） | `habits` 加 `schedule` 字段 + `isDueToday` 判定 | 中 |

### 🟨 P1 · 值得做 —— 留存与防丢

| # | 做什么 | 改动落点 | 复杂度 |
| --- | --- | --- | --- |
| P1-1 | **习惯日历热力图 + 最佳连续天数**：复用首页 XP 热力图组件，习惯维度铺开（Loop 同款） | `Museum.jsx` / Habits 页 | 低~中 |
| P1-2 | **坏习惯清零计时器**："已 23 天没刷短视频"里程碑庆祝 | 新轻模块（store + 小组件） | 低 |
| P1-3 | **自然语言日期解析**：输入"明天带资料""周五交报告"自动定「day」（Todoist／滴答的招牌交互） | `Todos.jsx` 快速添加框 | 低~中 |
| P1-4 | **ErrorBoundary + 存储配额预警**：白屏兜底 + 近 localStorage 配额时提示 | App 外层组件 + `saveNow` | 低 |

### ⚪ P2 · 远期 —— 特色与工程

| # | 做什么 | 改动落点 | 复杂度 |
| --- | --- | --- | --- |
| P2-1 | **阿咕每周数据解读**：用已有 API Key 生成周报文字总结（独有优势变现） | `ai.js` + 年鉴入口 | 中 |
| P2-2 | **云端真同步**：需要后端中转（云函数/对象存储），非纯前端闭环 | 全链路 | 高，暂缓 |
| P2-3 | **周报分享卡片**：canvas 生成像素分享图 → Web Share API 分享 | `Museum.jsx` + `charts.jsx` | 中 |
| P2-4 | **组件级 e2e + 体积预算 CI**：浏览器冒烟自动化 + 包体积失守即 fail | scripts + CI | 中 |

## 三、落地顺序建议

- **第一批（推荐先做）**：P0-1 习惯评分 → P0-3 月度报表 → P0-4 灵活排期（建立在已有数据上，"数据感知"主题一条线拉通）；P0-2 数值型习惯涉及存档迁移，放 P0 里最后。
- **第二批**：P1-1 热力图/最佳连续 → P1-2 坏习惯清零 → P1-3 自然语言日期 → P1-4 工程兜底。
- **远期**：P2-1（轮到阿咕发光）→ P2-3；P2-2 云端同步在拿到服务器之前不做；P2-4 可随 CI 就绪顺手接。
- 每批沿用既有规则：验证（lint/test/build + 冒烟）→ 更新三份文档 → bump 版本 → 提交推送。
