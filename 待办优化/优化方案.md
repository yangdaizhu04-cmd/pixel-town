# 拾光小镇 · 优化方案

> 记录时间：2026-09-07
> 说明：结合 Habitica / 人升(LifeUp) / Forest 三个同类标杆的调研，输出项目可优化的方向与分批落地路线。进度登记在 [优化清单.md](./优化清单.md)。

## 一、结论

项目底子好：游戏化闭环完整（XP/金币/花园/商店），「轻量、离线、治愈」是差异化优势。优化重点不在堆功能，而在三件事：

1. **意义感不够深**——奖励全是固定数值（+10 XP / +5 金币一刀切），做难事和划水没区别；
2. **数据洞察没做**——积累的数据没有反哺（无周报、无番茄统计）；
3. **形态没有进化**——纯网页，可用性天花板低（无 PWA、无系统通知、无暗色模式）。

## 三、分批评优项

### 🟥 第一批：玩家立刻能感受到的（游戏化深度）

1. **任务难度分级**：待办/习惯加「🌱 简单 / ⭐ 普通 / 🔥 困难」，XP/金币按难度阶梯给（简单 ×0.6、普通 ×1、困难 ×1.6），做难事有实打实的区别。
2. **自定义成就**：成就墙支持自定义「计数型成就」（如"读完 10 本书"：选指标 + 目标值，自动检测）+「手动心愿」两种，设奖励金币，解锁并入奖杯墙。
3. **愿望货架（现实奖励）**：商店新增一栏，自己「许愿」（写文字 + 定价格，如"看一场电影 50 金币"），买下后挂在货架上随时激励自己，兑现可标记。

### 🟨 第二批：让数据产生价值（洞察 + 分享）

4. 自动周报：周末汇总一周待办/番茄/金币/植物成长，写进复盘页。
5. 番茄钟统计页：每日/每周专注时段分布（复用 charts.jsx 像素图表）。
6. 成就分享卡片：热力图/徽章墙一键渲染成可保存的像素图。
7. 奖箱盲盒化：金额随机 + 小概率开出限时装饰/种子碎片。

### 🟩 第三批：形态进化（PWA + 移动 + 多端）

8. PWA 化：manifest + Service Worker，桌面/手机「添加到主屏」，App 感运行。
9. 番茄钟系统通知：专注/休息结束用 Notification API 提醒（soft opt-in）。
10. 暗色主题：像素风暗色（`prefers-color-scheme` 起步）。
11. 移动端触屏适配：底部 tab + 手势替换数字键快捷键。

### ⚪ 技术债（顺手清）

12. 字体子集化压体积（dist 1.6MB 里字体占 1126KB）。
13. 清理 28 条 lint 风格告警。
14. WebDAV 自动备份定时化（补"网盘在线验证"遗留待办）。
15. 给 pomo / store 迁移逻辑补少量单元测试。

## 四、落地顺序

- 第一批（先做）：1 → 2 → 3，纯前端、改动小、感知最强。
- 第二批（两周内）：4 → 5 → 6，建立在第一批数据上。
- 第三批（按需）：8 → 9 → 11 打包成一次「移动化改造」。
- 远期（需后端，暂缓）：好友合种/小镇互通——会破坏「零服务器」的纯粹性。
